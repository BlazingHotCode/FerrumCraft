# FerrumCraft Early Classic 0.0.14a_08

FerrumCraft's first Early Classic-ready release recreates the finite Creative
experience of Minecraft `0.0.14a_08` with a modern Rust and wgpu engine.

## Highlights

- Source-derived Huge `512 x 512 x 64` terrain generation.
- The original nine-block Creative palette and immediate interactions.
- Classic movement, collision, fluids, lighting, fog, and zombie behavior.
- Responsive HUD, deterministic terrain, compact saves, and asynchronous
  rendering improvements.
- Native per-user application storage for installed assets, data, saves, and
  logs.

## Downloads

- Windows x86_64: setup `.exe`, standalone `.exe`, and portable `.zip`.
- Linux x86_64: `.deb`, `.rpm`, portable `.tar.gz`, and standalone binary.
- macOS: `.dmg` and `.zip` for Intel and Apple Silicon.
- Source archives are generated automatically by GitHub.

The portable archives and installers include their seed resources. Raw Windows
and Linux binaries require the release resources ZIP to be extracted beside the
binary on first launch; Linux raw binaries also need `chmod +x`. macOS builds
are unsigned and may require approval in Privacy & Security on first launch.

This is an unofficial fan project and is not affiliated with Mojang Studios or
Microsoft.
