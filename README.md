# FerrumCraft

FerrumCraft is a Rust and wgpu recreation of Minecraft Early Classic
`0.0.14a_08`. It rebuilds the finite Creative experience on a modern renderer
while retaining the target version's small block palette, immediate building,
movement, lighting, fog, terrain generation, and simple zombie behavior.

This is an unofficial fan project. It is not affiliated with or endorsed by
Mojang Studios or Microsoft.

## Early Classic Release

The `early-classic-0.0.14a_08` release includes:

- A finite Huge `512 x 512 x 64` world.
- Source-derived Early Classic terrain generation, including caves, ores,
  flood-filled water and lava, beaches, and clustered trees.
- The nine-block Creative palette from `0.0.14a_08`.
- Instant block breaking and placement.
- Classic player dimensions, acceleration, gravity, jumping, collision, and
  water/lava movement.
- Binary skylight, directional face shading, linear distance fog, and
  exponential water/lava fog.
- G-spawned zombies with Classic wandering, jumping, movement, lighting, and
  animation behavior.
- A responsive Classic HUD with version/FPS text, crosshair, and selected-block
  preview.
- Deterministic terrain, compact modified-chunk saves, asynchronous chunk
  meshing, and modern GPU rendering.

## Controls

| Input | Action |
| --- | --- |
| `WASD` or arrow keys | Move |
| Mouse | Look |
| `Space` | Jump/swim |
| Left mouse | Break the targeted solid block |
| Right mouse | Place the selected block |
| Middle mouse | Pick the targeted block |
| `1`-`9` or mouse wheel | Select a block |
| `R` | Respawn |
| `Enter` | Set the current position as spawn |
| `F` | Cycle Classic view distance |
| `Y` | Toggle inverted mouse look |
| `G` | Spawn a zombie, up to 256 |
| `Esc` | Release the mouse |

Palette order: stone, dirt, cobblestone, oak planks, oak sapling, oak log, oak
leaves, sand, and gravel.

## Build And Run

Install a current stable Rust toolchain, then run from the repository root:

```console
cargo run --release
```

On first launch, the game copies the repository's packaged `assets/` and `data/`
into the OS application-data directory. Development builds should be launched
from the repository root so that first-run initialization can find those source
directories.

Development checks:

```console
cargo fmt -- --check
cargo check --all-targets
cargo test
```

## Release Downloads

GitHub releases provide:

- Windows x86_64 setup `.exe`, standalone `.exe`, and portable `.zip`.
- Linux x86_64 `.deb`, `.rpm`, standalone binary, and portable `.tar.gz`.
- macOS `.dmg` and `.zip` builds for Apple Silicon.
- Source `.zip` and `.tar.gz` archives generated by GitHub.

Installers and portable archives include the seed resources used to initialize
the per-user application-data directory. A raw executable downloaded by itself
needs the matching release resources ZIP extracted beside it on first launch.
On Linux, mark the raw `.bin` executable with `chmod +x` before running it.

## Application Data

FerrumCraft keeps writable game content in the native per-user data location:

- Windows: `%APPDATA%\FerrumCraft`
- Linux: `$XDG_DATA_HOME/FerrumCraft`, normally
  `~/.local/share/FerrumCraft`
- macOS: `~/Library/Application Support/FerrumCraft`

That directory contains `assets/`, `data/`, `saves/`, and `logs/`. Packaged
resources are installed there on first launch and refreshed when their resource
version changes. An existing repository-local `saves/world.json` is migrated if
the application-data save does not exist.

Generated terrain is reproducible and excluded from the save payload; only
modified chunks, player state, the selected spawn, and zombies are persisted.
Incompatible save versions are ignored rather than loaded into a different
terrain or physics implementation.

## Fidelity And Intentional Differences

FerrumCraft follows the archived `0.0.14a_08` behavior closely, but it is not a
binary-compatible copy of the original client. Intentional differences include:

- Bare Bones-inspired assets instead of original Minecraft textures.
- Direct right-click placement instead of the original build/break mode toggle.
- A deterministic Huge world seed.
- A modern wgpu renderer, chunk streaming, responsive HUD scaling, safe camera,
  and custom save format.
- Recreated zombie visuals rather than the original `char.png` skin.
